# 尺度可用性理论：这轮实质补强与正文接入建议

日期：2026-11-05。依据本轮提供的 `main(2).pdf` 和 `supplement(1).pdf`。

这次完成的是一份独立的定理扩展稿，而不是只增加写作建议。英文完整推导见 `geometry_theorem.pdf`，可编辑源文件、区间复核程序和两份运行结果均在同目录。原稿没有覆盖改写。

## 1. 实际增加了什么

原稿最强的结论是：相同观测、初始化、RED 更新和终端尺度下，所有受限尺度控制器均受阻，而开放中间带后可以实现正确入域及原始输出的风险保证。

这轮把其中的几何机制改写成了**从模型参数直接计算的充分条件**。输入包括模板几何、两个先验质量比、观测谱、步长和扰动预算；不再需要先构造一个虚拟平衡点，再依赖该平衡点定义混合权重。

令模板为 

\[
\mu_0=(0,0),\quad \mu_1=(1,0),\quad \mu_2=(-a,d),
\qquad r=\pi_1/\pi_0,\quad h=\pi_2/\pi_0.
\]

责任度的两个比值有显式表达式：

\[
R_v(s)=r e^{(s-1/2)/v},\qquad
H_v(s,t)=h e^{-(a^2+d^2+2as-2dt)/(2v)}.
\]

因此水平后验均值为

\[
m_v(s,t)=\frac{R_v-aH_v}{1+R_v+H_v}.
\]

利用这些公式，扩展稿给出四个相连的接口：

1. 低尺度与高尺度上的共同障碍，以及直接可算的尺度截断值；结论覆盖无界状态区域、无界高尺度和任意自适应切换。
2. 中间带的责任度上界、水平进展下界、常数步入域和首越无过冲；还证明了首次入域后继续运行的安全性。
3. 由模板距离间隔直接计算的终端不变性和残差界。
4. 保持原始 RED 输出的无条件风险界，包括异常观测矩控制、系数失配和局部终端误差。

这些条件不是把“存在不变集、存在进展通道”当作假设：每个界都已经写成模板、先验比和尺度端点的显式函数。矩形的边界仍由分析者选择，因此它是一套可检查的充分条件，不是必要充分判别器。

## 2. 新参数盒与可以直接使用的结论

新盒内几何和先验比可以独立取值：

| 参数 | 新范围 |
|---|---|
| 弱观测特征值 | \(0<\alpha\le10^{-3}\) |
| \(a\) | \([.98,1.02]\) |
| \(d\) | \([1.98,2.02]\) |
| \(\pi_1/\pi_0\) | \([1.27,1.31]\) |
| \(\pi_2/\pi_0\) | \([1.60,1.96]\) |
| 系数参数 \(\theta\) | \([-1,1]\) |

步长仍为 \(1/4\)，保留原来的噪声、正则系数和终端尺度耦合。这里的尺度变量 \(v\) 是总方差 \(\tau^2+\sigma^2\)，不是标准差 \(\sigma\)。

在整个参数盒上，新的共同受阻尺度范围为

\[
[v_L,.17]\cup[2.5,\infty).
\]

它包含原来的 \([v_L,.05]\cup[4,\infty)\)。这表示证明覆盖了更多受限尺度，不表示已经找到了成败的精确临界尺度。

中间带仍为 \([.69,.71]\)。在逐步 \(\ell_\infty\) 更新扰动不超过 \(10^{-4}\) 时，类 1 仍能在至多 25 步内到达正确终端区域。证明所用的保守数值为：

| 接口 | 复核界 |
|---|---|
| 中间通道内第三责任度 | \(<.043871\) |
| 水平后验均值导数 | \(<.558172\) |
| 入口处水平均值超额 | \(>.016303\) |
| 25 步比较序列 | \(>.534113\)，超过入口 \(.53\) |
| 第一次跨过入口后的水平坐标 | \(\le.647953\) |
| 终端最小平方距离间隔 | \(\ge.06\) |

56 项区间不等式在 60 位和 90 位十进制精度下均 PASS。输入是精确十进制字符串，没有轨迹网格或参数采样。这是同一算术实现的两次精度复核，**不是两份独立实现，也不是形式化证明**。

## 3. 还有一个比“扩大参数盒”更有解释力的结果

完整稿给出了第三分量先验比的显式可行区间：

\[
h_B(r)\le h\le\min\{h_E(r),h_C(r)\}.
\]

三个函数均直接由几何、尺度端点和目标进展裕量计算，不涉及数值平衡点或运行轨迹。

- 下界使第三分量在高尺度足够强，能够把水平后验均值压回错误区域。
- 两个上界让第三分量在中间通道被充分抑制，同时保留前两个分量产生的向右进展。
- 低尺度则因为初值靠近第一模板而产生另外一种阻碍。

因此，同一个先验比可以同时满足“高尺度阻碍”和“中间尺度允许进展”。这段机制比单独报告某个参数盒通过，更适合作为正文里的核心解释。可行区间为空只表示这些充分条件失败，不能反推所有算法都失败。

## 4. 第三类可以直接进入终端阶段

扩展稿使用

\[
\widetilde G_2=[-1.12,.01]\times[1.73,2.27].
\]

在整个新盒与原观测事件上，类 2 的初值已经属于这个区域；两个竞争模板的平方距离间隔分别至少为 1.848 和 2.828。该区域对终端更新不变，所以类 2 不必先做中间尺度更新。

由此得到更省调用的预设：**一次观测分类后，分别做 \(0/25/0\) 次中间更新，再切到终端**。原来的 \(0/25/5\) 保证没有因此失效；新的推导说明其中第三类的五次调用可以省去。

这会影响反馈效率的写法。原来“平均中间调用从 10.11 降到 6.38”仍然是原来两个协议之间的有效对照，但不能直接当作反馈相对这一更省调用预设的优势。若正文采用新协议，应同时让反馈方法在类 2 直接开始终端阶段，并用同一观测样本、初值、尺度和总预算重新运行对照。本次没有生成替代这些实测数值的模拟结果。

## 5. 风险结论保留下来了

保留 \(Z,u,\eta\) 相互独立，以及 \(u,\eta\sim N(0,\alpha^4 I_2)\)。终端更新精确、\(0<\alpha\le10^{-5}\) 时，新的预设仍使用

\[
K=25+n_\alpha,\qquad
n_\alpha=\left\lceil\frac{\log(12/\alpha^3)}{\log(4/3)}\right\rceil
\]

次总调用，并保证

\[
R_{\rm raw}\le R_{\rm oracle}+5\alpha^6,
\qquad
R_{\rm oracle}=\alpha^4\left(\frac1{1+\alpha}+\frac12\right).
\]

受限控制器的风险仍满足 \(\liminf R_{\rm bad}\ge.147\)。这是一组同一模型、同一更新下的可达性及风险分离。

对于近似更新，完整稿明确区分全局误差与终端局部误差。全局 \(10^{-4}\) 界控制入域和异常观测；更小的终端误差 \(\delta_L\) 只需在终端区域的并集上成立。残差增加 \(4\sqrt2\delta_L\)，从而 \(o(\alpha^2)\) 足以保留 oracle 比值，\(O(\alpha^3)\) 足以保留 \(O(\alpha^6)\) 超额风险阶。非零 \(O(\alpha^3)\) 误差并不自动保留常数 5。

## 6. 如何改正文，才真正提高贡献强度

建议把正文主线改成“可计算几何判据 → 非空独立参数盒 → 全控制器风险分离”。

第一，先陈述两种受阻机制和中间带机制，再给出能从模型输入直接检查的判据。把原来的特殊构造降为一个具体实例。不要把一般判据仅放在补充材料，正文只保留参数表。

第二，把最有价值的量词写清楚：对所有受限的观测、历史依赖控制器，任意长时间都不能越过共同边界；与此同时，一个固定宽度中间带给出统一有限步入域。常数步进展、无过冲与风险接口应作为同一结论的证据链。

第三，原来的虚拟平衡点构造仍然适合支持“共同平台局部校准”结果，但不要再让这个构造承担整个尺度分离定理的定义。新盒包含旧族的证明已经给出，两个结果可以在同一稿件中保持清楚的逻辑关系。

第四，把入口反馈放在效率层面。更省调用的预设已经说明，反馈不是达到主风险保证的必要机制。反馈是否节约调用，需要针对更新后的强基线重新检验。

第五，避免把普通后验集中、局部残差递推或条件均值正交性各包装为独立创新。这些工具的价值在于把共同障碍与原始输出的无条件风险连起来。

## 7. 这次推进的边界

**这是实质扩展，但仅凭它仍不能断言论文已经具有充分的理论贡献强度。** 可复用性提高了，特定平衡点依赖减轻了；“二维三模板模型是否足够重要”这一审稿问题仍然存在。

尤其需要保持以下边界：

- 仍是与观测特征方向对齐的二维三模板几何，不是一般高维或任意混合模型理论。
- 保留了弱观测特征值、两种噪声标准差和终端系数之间的耦合，没有解决独立参数变化的问题。
- 这是充分条件，不能宣称得到所有成功尺度的分类。
- 原有参数化未必缺少自由度，也未必是零测集；新贡献不能建立在这种未经证明的描述上。
- 新盒并不自动继承原文关于共享短平台或共同平台校准的所有结果。
- 已完成证明草稿与数值不等式复核；未完成外部独立验证和穷尽性的文献新颖性排除。

如果下一轮还只能投入一个理论方向，建议优先研究**解除至少一部分噪声与弱特征值的耦合**，明确哪些参数关系保证“观测可识别但受限动力学仍受阻”。这比继续微调步数和小数常数更可能提高结论的外部意义；本次没有把这一方向写成已完成结论。
