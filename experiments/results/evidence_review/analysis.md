## 正负结果怎样共同解释

最有价值的新机制是终端阶段也能完成跨区：中间前缀只需进入终端一步原像中的就绪区。区间认证支持整个E和带内任意历史，短预算结果验证选定中心处方的误差；两者范围不混同。改善认证工具带来的6/16到12/16覆盖，与就绪区带来的1–2调用节省分别陈述。

视觉开发的长预算均值主要受少数分支影响。去均值相对长低高的差异由68、90两个相反收益样本主导；相对共享的13个分流中8改善、5恶化。原始像素相对终端的改善几乎全来自旧patch37；相对共享的差异主要来自37、124、85。相对长低高在5000次几乎趋同。逐样本细节与描述性阈值见原开发分析末节。

1250次的球检查预测后续终端行为，不能称运行前或切换前的选参。五状态相对任一端点的反号不是共同障碍和通道的完整检验。浮点球、区间证书、有限步输出分离、不同极限固定点应分别命名。

## 标准网络验证的问题与官方来源

本项问题限定为：**尺度历史在标准学习去噪器上，是否造成可重复的有限预算或较长终端细化后的恢复差异？** 精确 MMSE 定理提供机制实例，网络结果检验经验相关性。

本地实现与单独执行的资源下载命令见 [标准网络运行说明](../../real_network.md)。随附配置是开发起点；是否启动与最新工作状态以根目录 status 为准。

[已完成的快速首轮](../drunet_fast_run/analysis.md)仅覆盖 DRUNet、一个高斯核和一档低噪声。其三个预算均选择终端单尺度，未获得非零前缀的平均开发收益；该事实不填补不同历史的长期分离或消失证据。

后续[固定非零历史诊断](../drunet_history_run/analysis.md)复用已存开发分数，比较真实不同的前缀，再做 32/64 次共同终端延长。结果支持所测时段的微小尺度历史差异及均值趋近，未获得平均 MSE 收益；局部距离增长保留为例外，不升级为极限吸引域结论。

2026-11-17 [原因核查](../drunet_history_run/cause_review/analysis.md)进一步区分证明错误、理论适用缺口和实验设计不足。主风险证明本轮暂未发现断裂；网络尚未验证共同障碍、通道与不同终端区域，公共求解器和短前缀覆盖也不充分。已存误差分解显示主要惩罚为同向偏移，不能单凭均值趋近定性机制边界。小规模开发作用力探查已准备，尚未运行，不增加网络正向证据。

后续[用户完成的两图探查](../drunet_cause_probe/analysis.md)已定位同状态的尺度作用反向、数据项主导消差和纯数据噪声响应。它增加当前开发配置的原因证据，仍不提供标准测试集正向恢复或定理机制外推证据。

首个网络建议用公开的 `drunet_gray.pth`，第二个用非 clip 的 `ffdnet_gray.pth`。两者在同一组固定权重中接收噪声标准差。FFDNet 官方仓库链接的 PyTorch 测试入口实际位于作者的 KAIR，不能假定原仓库根目录有同名 Python 文件。[DRUNet 实现](https://github.com/cszn/DPIR)、[FFDNet 仓库](https://github.com/cszn/FFDNet)、[作者提供的 FFDNet PyTorch 入口](https://github.com/cszn/KAIR/blob/master/main_test_ffdnet.py)。

[DPIR 论文 §3.2](https://arxiv.org/pdf/2008.13751)说明 DRUNet 用 **L1 损失**训练、训练噪声标准差范围为 0–50（8 位强度单位）。所以连“DRUNet 自动近似条件均值”也不能作为已知事实。[FFDNet 论文 §IV-A](https://arxiv.org/pdf/1710.04026)使用平方损失，报告范围为 0–75；训练目标本身也不保证得到精确 MMSE。主实验尺度建议限定在两者共同的正噪声范围内，内部图像与标准差统一除以 255。具体检查点的训练来源和实现版本需在接入时再确认。

替换为学习网络后，只能称固定形式的 RED 迭代；不继承精确 GMM 的标量势、后验协方差、模板竞争判据、模式标签或收缩证书。网络上的几何退火指**标准差按等比变化**，不是用理论几何证书选尺度。

[DPIR 原生去模糊代码](https://github.com/cszn/DPIR/blob/master/main_dpir_deblur.py)使用 HQS 数据解，并有逐迭代旋转/翻转以及可拆分网络推理的包装。主比较只复用网络，固定推理包装，关闭这些随迭代变化的增强；若使用切块，另记实际前向次数。原生 DPIR 单独列作恢复质量和耗时参照，其成功或失败不属于同一 RED 向量场的消融。

## 建议的最小验证协议（尚未运行前冻结）

下面是可执行方向的草案，尚未生成冻结计划。预算、开发图像和搜索量要经开发侧的计时与稳定性预试统一确定；本轮没有下载模型或数据，也没有运行网络。

| 项目 | 建议首轮设置 | 用途与范围 |
| --- | --- | --- |
| 图像与模型 | 灰度整图，先 DRUNet，再以 FFDNet 复核 | 第二网络使用同一问题定义和调参规则；第二网络的加入不以第一网络结果为正为条件 |
| 开发与评估 | 另取固定的 12–16 张开发图；BSD68 全集作本轮调度的保留评估，Set12 补充 | 开发/评估不重叠，记录网络已知训练来源；BSD68 不称预训练模型从未见过的基准。Set12 的 01、02、10 已在旧 patch 验证中暴露 |
| 任务 | 已知核的整图非盲去模糊；首轮用一个归一化高斯核和一个预定的 Levin09 运动核 | 建议高斯 25×25、标准差 1.6；运动核固定官方数组第 1 个。核选择不依据恢复收益；保存实际核及朝向 |
| 观测 | 建议噪声标准差 2.55/255、7.65/255，各 3 个预定独立种子 | 所有方法共享同一观测，不裁剪或量化加噪观测；种子复验不当作新增独立照片 |
| 边界 | 首轮周期卷积，明确其 A 与真正伴随 Aᵀ | 与训练网络内部 padding 分开说明；这验证已知合成退化，不推出真实相机模糊效果 |
| 有限预算 | 预试候选 K=16、32、64 次整图去噪 | 预试后一次性冻结；每个 K 的参数在开发集独立选择，不能拿 64 次最优参数称 16 次最优 |
| 共同终端延长 | 从一个预定锚点（候选 K₀=64）保存各调度状态，再追加同一终端映射 | 候选追加 64、256 次；不在追加后重新选前缀。若计时决定只做预定子集，结论明确限于该子集 |

DRUNet 论文的训练来源包含 BSD400、Waterloo、DIV2K 的 900 张和 Flickr2K 的 2750 张，不能直接把通常称为 DIV2K validation 的图像当作其未见开发集。开发来源要按所用检查点核对；调度的保留评估与预训练数据独立性分别记录。FFDNet 原论文也将 BSD68/Set12 用于基准评估，因此这里所说的保留仅针对本研究新增调度的选择过程。[DRUNet 训练说明](https://arxiv.org/pdf/2008.13751)、[FFDNet 数据说明](https://arxiv.org/pdf/1710.04026)。

### 固定更新与两种比较

主比较保持

\[
x_{k+1}=x_k-\gamma\{A^\top(Ax_k-y)+\lambda[x_k-D_{\sigma_k}(x_k)]\},
\qquad x_0=A^\top y.
\]

数据项是未按观测方差归一化的平方损失；残差不除以 σ²。不要直接搬用 GMM 的步长、λ 或终端尺度。对每个网络和退化条件，开发侧先按事先写定的准则选择一组共用的 γ、λ、σT，冻结后跨调度及预算使用；选择准则需交代是否偏向了某条调度。主比较中只改变尺度历史。

另表允许每家族按预算调优 γ、λ、σT，回答其可达到的恢复质量；这一表不用于同终端映射或同向量场的因果解释。再用一个预定的正则化最小二乘初值作小范围对照，ρ 只在开发集选取，同样共享给各家族。无需为这次机制验证扩成任务或网络排行榜。

### 调度家族与公平选参

每个目标 K 都在相同开发图像、噪声和误差目标上选参，不读取测试真值。可以按已知核与观测噪声条件选全局处方，不能逐张测试图取最优处方。主目标建议为等权逐图 MSE，噪声先在图内平均。

| 家族 | 明确定义 | 应调参数 |
| --- | --- | --- |
| 终端单尺度 | K 次均为 σT | 主表无历史参数；附表允许调终端/求解器参数 |
| 两端点历史 | 前缀仅用 σT、σH，之后用 σT；含高→低、低→高→终端、分块交替 | σH、切换位置/块长和顺序；只比较规定家族，不称所有两端点控制 |
| 共享平台 | 所有测试图共用 σM 做 m 次，再到 σT | σM、m，包含 m=0 的终端候选；此处“共享”不含 GMM 观测分类 |
| 等比退火 | m≥2 时 σk=σH(σT/σH)^{k/(m−1)}，k=0,…,m−1，随后保持 σT | σH、m；退化情形包含终端候选 |

每家族的尺度范围、前缀长度上限、共同最少终端调用和搜索上限预先写清。建议主表预留至少 K/4 次共同终端调用，取整规则固定。两端点组不能只留一个方便失败的短高低前缀；共享平台也不能沿用认证预设中心而省略独立选参。

搜索控制要同时报告候选数和开发侧网络调用数。参数较多的家族使用相同搜索调用上限或等额候选评估；终端单尺度无需虚构无意义候选。候选和次序、平局规则、无穷/发散的处理在看测试结果前保存，不能只给某一方法失败后扩网格。开发稳定性需要先检查，但不删去测试中实际失败的图像。

### 必须保留的读数与诊断

- **恢复误差。** 每图保存平方欧氏误差及 MSE=SSE/N；PSNR 在 data_range=1 下逐图计算再等权平均，不能从平均 MSE 代替平均 PSNR。SSIM 的窗口、边界和数据范围固定。主数值用未量化浮点输出；若另报裁剪到 [0,1] 的标准质量数，所有方法同样处理并分列，不把裁剪反馈给迭代。
- **配对稳定性。** 各核、噪声、预算分表列均值、逐图配对差、中位数和胜/平/负数量；重复噪声先在图内汇总。置信区间以整图为重采样单位，同一图的噪声、核和方法一起保留，避免把 patch、像素或噪声复验当独立图像。展示图用预定图或最好/中位/最差配对样本，不只挑正例。
- **尺度历史。** 记录共同终端阶段的两输出 RMS 距离，以及按像素归一化的 RED 场范数。可用已执行更新的步长除以 γ 得到残差，注明它对应更新前状态；若在最终状态额外调用网络求残差，计入诊断开销。神经网络没有已知标量势时不画作“RED 目标下降”。
- **弱观测方向。** 对周期模糊，按已知 A 的频谱预先定义弱增益频带，分解真值误差和调度输出差异。阈值仅由算子/开发协议确定，检查收益是否出现在弱方向。这是经验诊断，不是 GMM 模板竞争或共同障碍的证据。
- **实际代价。** 保存逻辑去噪调用、实际网络前向、整图大小、时间和峰值显存。离线尺度探针单列成本；若参与在线选参，其调用必须纳入恢复预算。固定权重、eval 模式、padding、精度和推理包装，不在中途做 uint8 往返、裁剪、换权重或未计费增强。

### 结果允许支持到哪里

| 观察结果 | 可以写的结论 |
| --- | --- |
| 公平调参后仅短预算有稳定误差改善，共同终端延长后趋同 | 在所报数据、噪声、初始化和预算内有有限预算收益 |
| 长延长后输出仍分离，同时两条轨迹残差都小 | 在所测时长和数值容差内存在持续历史差异；不直接称不同极限吸引域 |
| 上述分离还伴随多数图像/预定条件上的误差改善 | 增加“在这些标准网络设置中，历史差异与恢复质量相关”的经验支持；不外推任意受限控制风险下界 |
| 分流但没有误差收益，或充分调参共享/两端点也达到同等质量 | 分流不保证更准，中间尺度不是该实验中的独有必要条件 |
| 差异只依赖一个网络、初值或极少图像 | 限定经验结论，保留全部预定条件和负结果 |

执行顺序建议为接入并验证固定 RED/去噪接口 → 仅开发侧计时和有限调参 → 保存本轮计划及处方 → BSD68/Set12 冻结评估 → 同协议 FFDNet 复核。原 GMM 开发未过门槛的结论保留；新网络线不预设必须出现永久分离，也不以少量正例回头定义尺度约束。
