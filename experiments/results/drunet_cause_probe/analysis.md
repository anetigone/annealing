## 1. 低噪声的额外尺度确实把状态推离真值

在相同终端参考状态 x 上，只替换下一次调用，令 `u=γλ(Dσ(x)−D5(x))`。误差变化为 `2〈x_next,5−x*,u〉/N+||u||²/N`。这样固定了更新前状态与数据项，直接测量更换尺度的立即作用，不把不同轨迹的输入差异混入比较。

在第 64 次状态上，两图等权均值为：

| 下一次网络标准差（×255） | 低观测噪声 2.55：相对 σ5 的 MSE 变化 | 高观测噪声 7.65：相对 σ5 的 MSE 变化 |
| ---: | ---: | ---: |
| 10 | +1.4607e−6 | −5.4035e−6 |
| 25 | +3.5455e−6 | −1.2164e−5 |
| 49 | +4.5534e−6 | −1.2709e−5 |

低噪声的两图×四状态（0/16/64/128）×三种较大尺度，24/24 次替换都增加 MSE，最小增量 8.02e−7。高噪声在状态 0 的 6/6 次替换同样增加误差，到 64/128 状态则为 12/12 次降低误差。因而尺度的作用与噪声、恢复阶段有关；不能把作用概括为“大尺度总是过平滑”或“高噪声总该立即用大尺度”。

用已存标量还可比较同一状态上“加入正则化”与“仅做数据更新”。写 `r=λ(x−Dσ(x))`、`d=Aᵀ(Ax−y)`、`e=x−x*`，额外 MSE 为

\[
-2\gamma\langle e,r\rangle/N+2\gamma^2\langle d,r\rangle/N+\gamma^2\|r\|^2/N.
\]

以 Cauchy–Schwarz 包住未保存的 `〈d,r〉`：低噪声的全部 32 个状态/尺度组合，其增量下界均为正；高噪声在 64/128 状态的全部 16 个组合，其增量上界均为负。[标量界与原测量](review/force_effects.csv)。这是测得数值上的代数方向诊断，不是向外舍入证书或终端风险保证。

尺度接口的作用并不微弱：低噪声状态 64 上，正则项 RMS/数据项 RMS 的逐图比值均值，σ5/10/25/49 分别为 .575/1.130/2.549/4.101。σ10 残差相对 σ5 的最佳标量倍增仍留下约 31% 正交能量；σ25/49 则约 74%/87%。尺度既改变强度也改变方向，不能用统一的残差倍率或假定的 σ² 规律解释。λ=.1 不在主定理系数窗口内，是适用范围缺口；它并未使当前网络正则项失去作用。

单步误差增加本身并不排除某个更长控制器先增加误差再跨区。这里同时检查了已经冻结的整段平台：

| 观测噪声（×255） | 64 次平台相对终端的平均 MSE 增量 | 128 次增量 |
| ---: | ---: | ---: |
| 2.55 | +0.5027% | +0.1146% |
| 7.65 | −0.9561% | −0.8285% |

百分比为等权逐图 MSE 均值的比值差，两图分别也保留同一方向。高噪声处方是原低噪声处方的固定控制，并非调优后的高噪声性能。

## 2. 共同尾部主要由数据项消除差异

令 `δ=x_history−x_terminal`，`δD=D5(x_history)−D5(x_terminal)`，`h=Bδ+λ(δ−δD)`。公共尾部逐步满足

\[
\Delta\|\delta\|^2/N
=-2\gamma\langle\delta,B\delta\rangle/N
-2\gamma\lambda\langle\delta,\delta-\delta D\rangle/N
+\gamma^2\|h\|^2/N+\text{roundoff}.
\]

按两图等权平均距离平方的净下降归一化，64→128 次的贡献为：

| 噪声 | 历史 | 数据项 | 去噪器项 | 步长平方项 |
| ---: | --- | ---: | ---: | ---: |
| 2.55 | 两端点 | 103.66% | −2.61% | −1.05% |
| 2.55 | 平台 | 104.25% | −3.17% | −1.07% |
| 2.55 | 等比 | 90.89% | 10.02% | −.91% |
| 7.65 | 两端点 | 96.24% | 4.83% | −1.06% |
| 7.65 | 平台 | 95.98% | 5.10% | −1.07% |
| 7.65 | 等比 | 88.59% | 12.35% | −.94% |

正值贡献于距离平方的减少，负值抵消减少；微小浮点项另存。低噪声平台的去噪器项累计扩大差异，所以数据项贡献超过 100%。低噪声平台两图合计 128 个尾部步骤中，90 步的 `〈δ,δD〉/||δ||²>1`；32→64 次的每个噪声/两端点或平台组（两图×32 步）均为 64/64 步大于 1。不能把当前趋近称为“终端去噪器收缩”。

这种局部放大也未压过数据项：64→128 次的全部 768 个成对步骤中，`β_eff+λ(1−a)>0`，其中 `β_eff=〈δ,Bδ〉/||δ||²`、`a=〈δ,δD〉/||δ||²`。最小值约 .00655；真实完整 RED 的逐步距离比均小于 1。低噪声平台的平均 β_eff 从第 64 次约 .0614 降至第 127 次约 .0193，剩余位移逐渐偏向较弱观测方向，衰减也放慢。

这些是沿实际成对轨迹的恒等式与方向量。它们不等同于删去某一项后重跑的整段效果，也不是整个邻域的 Lipschitz 界或共同吸引域证书。单步恒等式最大浮点余差为 3.86e−13，远小于主贡献。[逐图分解](review/transport_contributions.csv) · [等权汇总](review/transport_pooled.csv)。

## 3. 效果并非仅由边缘造成

边缘固定为 32 像素，主指标仍为未裁剪整图 MSE。低噪声平台在 64 次的内区 MSE 增量为 +1.3920e−5，边缘为 −1.9093e−6；128 次相应为 +4.8803e−6、−5.3196e−6，均为逐图区域均值再等权平均。内区的损失持续存在，边缘改善反而抵消部分整图损失。

高噪声平台在两种区域都改善：64 次内区/边缘 MSE 增量分别为 −1.8234e−5/−3.1608e−5。低噪声等比在 128 次的极小整图收益则来自边缘，两个内区仍分别略差。周期退化与网络填充值得继续注意，但它们解释不了本批低噪声平台的内区损失或高噪声内区的作用反向。[区域差和按面积加权贡献](review/paired_endpoints.csv)。

## 4. 数据项的恢复与噪声放大可单独重构

对源计划中的同两图、同标准噪声样本，另用 NumPy 双精度周期算子计算纯数据更新。设频率平方增益为 β，`h0=1`、`h_{k+1}=(1−γβ)h_k+γ`；从反投影出发，输出分成无噪声响应 `h_k Bx*` 与实际噪声响应 `νh_k Aᵀε`。两者误差平方加上本次噪声实现的交叉项，逐项重构 MSE；不把交叉项按期望置零。双精度参考与原 GPU 单精度纯数据端点的最大 MSE 差为 1.03e−9，主算法与原指标不改。

64→128 次的两图均值变化为：

| 观测噪声（×255） | 无噪声恢复偏差平方变化 | 实际噪声响应平方变化 | 交叉项变化 | 总 MSE 变化 |
| ---: | ---: | ---: | ---: | ---: |
| 2.55 | −1.6221e−4 | +6.8863e−5 | −2.3185e−7 | −9.3575e−5 |
| 7.65 | −1.6221e−4 | +6.1977e−4 | −6.9554e−7 | +4.5687e−4 |

无噪声恢复进展相同，噪声幅度乘三使噪声响应能量乘九；较高噪声时，后者超过恢复进展。原终端 RED 虽比纯数据更新更好，高噪声的 64→128 次 MSE 仍回升约 8.41%。结合后期同状态正则化有益的测量，当前固定终端配置没有阻止误差回升；延长计算不是恢复误差的保证。

这是纯数据参考的线性分解，不是对整个非线性网络风险的统计偏差/方差估计，也不把纯数据参考列为匹配网络调用预算的质量基线。[同观测重构](review/data_reference.json) · [计算代码](../../code/real_network/data_reference.py)。本轮只在远端做这项小规模 CPU 重构，网络调用为零。

## 5. 对定理与后续实验的判断

当前数据支持的是状态和噪声依赖的先验作用，以及数据项主导的有限步消差。没有定位到实现的尺度单位、更新式或缓存错误；也没有出现能检验主风险定理的完整共同障碍—中间通道—不同终端区域链。网络输出不同、去噪器局部放大或误差符号变化，都不能代替这条链。

因此，本批更具体地解释了原配置为什么会得到小幅负结果，**未把主定理推广到 DRUNet，也未用网络结果推翻主定理**。此前“λ 小所以先验没起作用”“差异变小所以去噪器收缩”“只是边缘问题”三种简化解释，均不能作为本批原因。原论文的实际适用缺口仍是：怎样从网络和算子事先检查相关几何，并选择有机制的尺度范围。

若下一步评估标准恢复效用，先在开发侧校准共同 γ/λ/σT，并补入短前缀与近终端尺度，再冻结评价；若检验正向可达性机制，应先检查网络的方向放大能否压过相关观测方向的作用，再检查通道和不同终端区域。两条工作分开，不用制造输出分离替代恢复改善。当前没有新参数选择、第二网络或扩大的测试队列。

离线分解与出图入口为 [summarize_cause.py](../../code/real_network/summarize_cause.py)，复跑写新目录。所有结论限于两张已经用于开发的图、一个核、一个噪声实现及冻结处方；未量化选择不确定性或重复噪声风险。
