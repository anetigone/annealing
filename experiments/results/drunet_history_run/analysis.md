# DRUNet 非零尺度历史：差异很小，平均差距随终端细化减弱

本批完整结束，68 张图均正常。四种实际不同的尺度历史产生了不同输出；在 64、96、128 次读数上，平均输出距离和平均 MSE 差距逐步减小。**按预先采用的平均像素 MSE，三种非零前缀仍略差于终端单尺度，没有获得总体恢复收益。** 128 次时输出尚未重合，少数图像的距离反而增加；不据此宣称统一收缩、相同极限或不同吸引域。

胜/平/负采用沿用的绝对 MSE 阈值 1e−8。所有读数上三种非零前缀的平均 MSE 都高于终端；128 次时其增量分别为 2.1303e−6、3.9932e−6、3.0079e−7。原有图像 bootstrap 区间仅条件于这批图像、固定选择及单个噪声实现，没有开发选择不确定性或多重比较保证。

等比在 128 次的平均 PSNR 比终端高 .0003896 dB，但平均 MSE 仍略差、平均 SSIM 也略低（.784374 对 .784448）。这是逐图取对数再平均与直接平均 MSE 的聚合差异，并非数据矛盾；不能据此改换主指标宣称收益。三种非零前缀与终端的 128 次平均 PSNR 差绝对值均小于 .0013 dB。

所有方法对、所有图像、所有保存读数的输出 RMS 均非零，本批没有相同序列的轨迹复用。相对终端的逐图 RMS 再平均如下，像素强度范围为 0–1：
