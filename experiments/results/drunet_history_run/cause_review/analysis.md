# DRUNet 负结果的原因核查

更新：2026-11-17。核查对象是已完成的 `drunet_fast_run` 和 `drunet_history_run`。本轮复核证明和实现、分析已存结果，并准备小规模开发侧诊断；没有启动新的预训练网络轨迹。先前把结果归为“机制适用边界”过早：目前尚未区分普通偏差/收缩、处方覆盖不足和多稳定机制缺失。

后续：用户已完成[两图作用力探查](../../drunet_cause_probe/analysis.md)。测量定位了低噪声的方向性损失、数据项主导消差及高噪声后期的噪声放大；并不支持把消差归因于去噪器收缩。下文保留探查前的审查和处方，实际结果以链接分析为准。

## 当前判断

**已经找到的是理论到实验的连接缺口和实验设计的诊断不足，尚未找到主风险定理的反例或更新实现错误。** “精确 MMSE + 弱观测”本身不推出退火收益；主定理还验证了特定模板竞争下的共同障碍、通道和不同终端区域。DRUNet 的这些条件没有被检查。有限步输出分离或均值趋近均不能代替它们。

以下分开记录已确认事实、解析解释和仍待测的网络原因。原始结果、处方与主误差口径保持不变。

## 1. 主定理检查到哪里

复核了[主定理](../../../../paper/latex/scope_extensions.tex)、[独立噪声证明](../../../../paper/latex/scope_proof.tex)、[障碍/通道/终端证明](../../../../paper/latex/scale_geometry_proof.tex)和[通用风险接口](../../../../paper/latex/reachability.tex)。本轮没有发现以下连接断裂：

- 低、高尺度右边界向内，自身坐标保序把边界估计扩至整个错误区域；它阻挡任意受限切换，而非仅两个常值策略。
- 中间尺度沿整个通道有统一进展，跨界落点受控，且进入后的剩余中间调用保持准备区；不是把单步向外当作入域。
- 三类分别检查入口，观测分类在事件内正确。分析中的类别不作为控制器输入。
- 终端误差递推相对仿射参考点成立，原始迭代输出承担误差；事件外由预算一致的四阶矩界控制。
- 风险下界用条件 L2 反三角不等式，未把事件内截断噪声继续当作无条件 Gaussian。独立噪声的尾界满足所述低噪声条件时才给出趋零上界。

### 定理到 DRUNet 缺的连接

1. 定理要求 `c(vL)≥.999, λ≤1.002`，从而全部可用尺度的有效系数均在约 1 附近；这还强制 `σL/τ≥sqrt(333)`。网络实验固定 `λ=.1`，不存在已识别的共同分量宽度 τ 或可计算的 c(v)。不能把 λ 的不同本身当作已测原因，更不能仅改成 1 就宣称对齐了理论。
2. 定理的第三模板要在高尺度提供反向竞争、在中间带受到充分抑制。网络实验没有识别这种竞争，也没有终端存在两个相关稳定区域的证据。弱频带误差大不等于有多吸引域。
3. 定理允许有界更新扰动，因而并非完全没有近似鲁棒性。但把网络写成 `D_hat=D_exact+e_D` 后，更新误差为 `γλe_D`，需要在全部相关区域验证误差界，终端风险趋零还要求更精细的局部误差随噪声缩小。平均 AWGN 去噪质量不能提供这些界；目前没有可验证的精确参考去噪器。
4. DRUNet 用 L1 训练，不能直接视作 MMSE；官方去模糊入口使用 HQS 的 FFT 数据子问题，也不提供当前固定 RED-GD 的保证。[原论文 §3.2](https://arxiv.org/pdf/2008.13751)、[官方入口](https://github.com/cszn/DPIR/blob/master/main_dpir_deblur.py)。即使改用平方损失网络，上述几何和近似界也仍需检查。

因此，缺口主要是**可验证的网络适用条件与预测方法**。这比“定理只需再多几个数据集验证”更实质；现有特殊族充分条件尚不能指导真实网络上怎样选出有机制的退化和处方。

## 2. 实现与设计分别是什么问题

复核当前实现：`common.red_trajectory` 的梯度为 `Aᵀ(Ax−y)+λ(x−Dσ(x))`；数据项没有噪声方差归一化，残差没有除以 σ²。图像、观测噪声和输入网络的标准差分别只除以 255 一次。DRUNet 的输入是图像加噪声尺度通道，输出直接是图像；原版无偏置结构严格加载。其结构和随机权重前向与[官方 UNetRes](https://github.com/cszn/DPIR/blob/master/models/network_unet.py)的兼容检查已有保存，未在本轮重复为新证据。卷积朝向、伴随和更新公式的小检查已有通过。

共享观测在家族循环外生成，每条轨迹重新从相同反投影开始。评分缓存只合并完全相同的整条尺度序列，非零历史对照不发生这种复用；首轮与第二轮的终端逐图结果完全一致。保存的开发分数确实全部在数值容差外输给终端，零前缀不是平局代码制造的。当前未找到会把非零调度错误计算成终端或把真值用于测试选参的实现问题。这些检查尚不等同于对真实权重的全部算子数值作独立上游比较。

已经确认的设计不足是：

- 公共步长 .25、λ=.1、σT=5/255 是未经求解器校准的起点。本批能回答这些固定值下的条件性比较，无法判断效果是否只是这个起点决定。
- 64 次预算的平台只抽到前缀 32/48 次；σ=10 只配到 32 次。没有 1/2/4 次短前缀，也没有 5 到 10 之间的近终端尺度。几何前缀虽有 16 次，不能补齐平台缺项。逐预算选参做了，但候选覆盖仍粗。
- “两端点”家族也在 10/25/49 中选择高端；它并没有对应定理里预先分开的低、高受限区间，而平台的尺度与它重叠。家族名称是历史形状，不能当作定理中不同可用尺度集合的实验证明。
- 没有保存端点张量、同状态不同尺度的网络输出或公共尾部的成对更新项。仅凭现有 MSE、距离和场 RMS，无法判定偏移是加强平滑、方向改变、走得较慢还是多稳定分流。
- 周期模糊与网络的复制/零填充是不同的边界约定。配对一致不代表边界效应不会影响尺度比较；旧结果没有内区/边缘分解，尚不能排除这一解释。它是待测的设置因素，不是已发现卷积伴随错误。

[实际候选覆盖](candidate_coverage.json)。这些不足不取消原公平调用预算下的条件性负结果，也不支持事后在 BSD68 上挑新参数。

## 3. 已存结果能进一步说明什么

令 `e=x_terminal−x*`，`d=x_history−x_terminal`。现有逐图 MSE 与输出 RMS 足够恢复恒等式

\[
\Delta\mathrm{MSE}=2\langle e,d\rangle/N+\|d\|^2/N.
\]

64 次时，均值分解为：

| 历史 | MSE 增量 | 位移平方项 | 与终端误差交叉项占增量 |
| --- | ---: | ---: | ---: |
| 两端点 | 8.0303e−6 | 2.6852e−7 | 96.66% |
| 平台 | 1.5424e−5 | 9.6247e−7 | 93.76% |
| 等比 | 1.6836e−6 | 2.0918e−8 | 98.76% |

主要惩罚来自与现有误差同向的偏移，而非位移平方项本身。这是代数归因，尚不能从内积的符号直接断言偏移来自过平滑或延迟收敛。64 次时三者的增量约 55%–59% 位于预设弱频带，其余频带也贡献损失；到 128 次弱带占增量约 75%–85%。终端自身仍在明显恢复：64→128 次平均 PSNR 上升 .41761 dB，像素 MSE 下降约 8.76%。128 次并非已经到达长期状态的证据。

[逐图误差分解](error_decomposition.csv) · [汇总](error_summary.csv)。使用全部 68 图、单个原评价噪声，未按这些量筛图或改选策略。位移平方使用逐图 RMS 的平方再平均，未用平均 RMS 的平方替代。

早期一张开发图的 GPU 预试还显示：同一高斯核的 64 次平台在低噪声时 MSE 增加约 .454%，较高噪声时下降约 1.222%；Levin 核相应为 +2.244%/−4.187%。[旧预试读取](preflight_noise_contrast.csv)。这只是已有线索：单图、不同噪声实现和不同于第二轮的历史，不能据此把原因锁定为噪声强度，更不能升级为高噪声普遍收益。

## 4. 一种不需要任何证明错误的解析解释

考虑最简单且完全匹配的精确 MMSE：`x*~N(0,τ²)`，无噪声观测 `y=sqrt(β)x*`，`0<β≤1`，反投影初值 `x0=βx*`。Gaussian 去噪器和 RED 为

\[
D_\sigma(x)=\frac{\tau^2}{\tau^2+\sigma^2}x,\quad
c_\sigma=\lambda\frac{\sigma^2}{\tau^2+\sigma^2},\quad
x^+=(1-\gamma(\beta+c_\sigma))x+\gamma\beta x^*.
\]

在 `γ(β+λ)≤1` 下写 `xk=ak x*`，有 `0≤ak≤1`。对于全部 `σk≥σL`，系数递推保序且 `cσ≥cL`，逐步归纳得到 `a_history≤a_terminal≤1`。因此更高尺度的任意前缀只会加重已有的欠恢复，Gaussian 总体风险 `τ²(1−ak)²` 不低于终端策略。进入共同尾部后

\[
x^{\rm history}_{m+n}-x^{\rm terminal}_{m+n}
=[1-\gamma(\beta+c_L)]^n
(x^{\rm history}_m-x^{\rm terminal}_m).
\]

较高尺度更差、差异随尾部减小，在这个无模板竞争的精确 MMSE 模型里是可证明的正常行为。它说明弱方向和 MMSE 并不足以产生主定理的优势。它是 DRUNet 的一个待区分解释，**不是将网络拟合成 Gaussian 后得到的已确认原因**。[固定三组 β 的小规模数值核对](gaussian_reference.json)，没有搜索正例。

## 5. 下一步只补能区分原因的测量

已准备 [probe_cause.py](../../../../experiments/code/real_network/probe_cause.py)，沿用冻结的 64 次非零历史和已有开发集顺序的前两图，不读取 BSD68。固定噪声标准样本、只将幅度从 2.55 改为 7.65，历史处方不随新噪声重调；额外噪声只用于因果探查，不是调优后的性能表。它测量：

- 同一状态下 σ=5/10/25/49 的残差大小、方向和相对数据项的比例；用最小二乘投影区分是否主要是残差倍增。
- 高尺度替换一次终端更新造成的 MSE 变化，精确分成交叉项、位移平方项和弱频带部分；这些真值量仅事后解释，不用来选测试调度。
- 公共终端尾部的距离变化分解。设 `δ=xh−xL, δD=D_L(xh)−D_L(xL)`，`h=Bδ+λ(δ−δD)`，则

\[
\Delta\|\delta\|^2/N
=-2\gamma\langle\delta,B\delta\rangle/N
-2\gamma\lambda\langle\delta,\delta-\delta D\rangle/N
+\gamma^2\|h\|^2/N.
\]

逐步报告数据项、去噪器割线项、步长平方项以及浮点余差，以判断谁在消除或放大历史。沿途割线并非整个区域的 Lipschitz 证书。

- 同观测的纯数据更新作参考，以及真值加 AWGN 后的常规去噪检查，用于识别接口/权重明显异常与默认正则化的作用。
- 同时分开看内区和边缘的误差/单步反事实，边缘宽度为 `min(32, 最短边//4)` 像素，排查周期退化与网络填充的影响；主误差仍用整图，不事后改裁边口径。

默认 **2166 次前向**，其中 64 次专门核对诊断积分器与原 `red_trajectory` 的 16 步逐位一致；按原 28 ms/次约 61 秒纯推理，另有读写、FFT 与统计开销。未运行新网络探查；继续按用户安排由其同步、启动。命令见[运行文档](../../../real_network.md#原因定位的小规模开发测量)。本地仅用 32×40 合成图与线性假去噪器完成小流程：1083 次计数吻合、两次积分器核对逐位一致、距离恒等式浮点余差最大 1.76e−11。[检查记录](probe_checks.json)。

若这些测量显示普通正则化偏移与公共尾部收缩已解释观测，稿件应明确机制尚未在网络中出现；若显示局部放大或多稳态线索，再另行设计终端稳定性与可达性检查。当前不把任何一种分支当成已经确定的结论。
