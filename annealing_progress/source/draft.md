# 第一部分：三模板有限预算证书

# R1：三模板的有限预算路径选择——计算机辅助定理草稿

日期：2026-10-30。状态：下述区间证书已运行通过；解析论证与验证器尚未经独立审阅或形式化证明。

本轮沿用原版精确 MMSE、未除以噪声方差的 RED-GD。建立了一组显式三模板参数及其扰动邻域，在相同观测、反投影初始化、64 次去噪器调用和终端目标下，渐进退火进入正确终端吸引域，而两种对照在指定类别上进入错误不变邻域。证书包含整个噪声尺度区间、整个参数盒和整个观测噪声事件，不是网格点测试或 Monte Carlo 统计。

**本轮最重要的调整：稳定驻点分支确实存在，但成功的 64 步轨迹并不始终贴近它。** 在第三类的第 50 步，已经证出轨迹离该分支超过 0.50，且当前位置具有负曲率。因此，稳定分支跟踪作为保守慢调度的充分机制保留；64 步主结果改用允许短暂扩张的逐步误差管直接证明。不能把快速成功解释成“每一步都在稳定分支附近收缩”。

## 1. 模型、参数族和比较口径

设去噪先验为三个同协方差高斯的混合：

\[
p(x)=\sum_{i=0}^2\pi_i\mathcal N(\mu_i,\tau^2I_2),
\qquad \pi_i=\frac{a_i}{a_0+a_1+a_2}.
\]

以下十进制数全部作为**精确有理数**解释：

\[
\bar\mu_0=(1.38,-1.03),\quad
\bar\mu_1=(-0.22,-0.19),\quad
\bar\mu_2=(-1.16,1.22),
\]

\[
\bar A=\begin{pmatrix}-0.08&0.24\\-0.95&-0.31\end{pmatrix},
\quad \bar\tau=0.15,\quad\bar\lambda=1,\quad\bar\gamma=0.35,
\quad\bar a_i=1.
\]

令 \(\delta=10^{-4}\)。参数族由以下**逐项独立**的约束给出：

\[
|\mu_{ij}-\bar\mu_{ij}|\le\delta,
\quad |A_{ij}-\bar A_{ij}|\le\delta,
\]

\[
|\tau-0.15|\le\delta,\quad
|\lambda-1|\le\delta,\quad
|\gamma-0.35|\le\delta,\quad
|a_i-1|\le\delta.
\]

参数选定后，在各方法之间保持完全相同。其内部是非空开放参数族；共用各向同性分量协方差仍是本模型的结构约束。本轮没有声称对任意独立协方差扰动也成立。

证书还验证了

\[
0.06I\prec A^TA\prec1.01I,\qquad
\min_{i\ne j}\|\mu_i-\mu_j\|>1.69,
\]

\[
\left|\det(\mu_1-\mu_0,\mu_2-\mu_0)\right|>1.46.
\]

因此观测满秩，模板不共线，模板间距不消失，分量方差和混合权重均严格为正。

干净真值取 \(x^\star=\mu_Z\)，观测与初始化为

\[
y=A\mu_Z+\eta,\qquad x_0=A^Ty.
\]

确定性结论在事件

\[
E=\{\|\eta\|_\infty\le10^{-3}\}
\]

上逐点成立。概率推论再令 \(Z\) 在三类上等概率，独立于 \(\eta\)。真实类别频率固定为均匀分布；允许扰动的是去噪先验的混合权重。真值是模板，不是从方差 \(\tau^2\) 的连续 GMM 分量中抽取的样本。

算法保持为

\[
x_{k+1}=T_{\sigma_k}(x_k)
=x_k-\gamma\left[A^T(Ax_k-y)+\lambda(x_k-D_{\sigma_k}(x_k))\right].
\]

终端噪声 \(\epsilon=0.35\)，高噪声为 2，预算 \(K=64\)。三种调度为：

| 方法 | 64 次调用的噪声值 |
|---|---|
| 常值 C | 全部为 0.35 |
| 预热后跳变 J | 前 12 次为 2，后 52 次为 0.35 |
| 渐进 A | \(\sigma_k=2-1.65k/63+\zeta_k\)，\(k=0,\ldots,63\)；\(\zeta_0=\zeta_{63}=0\)，\(|\zeta_k|\le10^{-4}\) |

最后一个条件覆盖精确线性调度及其一个显式邻域。所有这样的调度自动严格递减，且

\[
\frac{1.65}{63}-2\cdot10^{-4}
\le\sigma_k-\sigma_{k+1}
\le\frac{1.65}{63}+2\cdot10^{-4}.
\]

这里的充分条件是**每个噪声值离线性调度不超过 \(10^{-4}\)**；仅满足上述相邻差值范围，并不自动满足整个调度的偏差约束。调度不依赖真实类别。

## 2. 64 步主命题

**命题 A（带显式扰动半径的有限预算路径选择）。** 对第 1 节整个参数族、每个 \(\eta\in E\)、每个允许的渐进调度：

1. 对所有 \(Z=0,1,2\)，
   \[
   \|x_{64}^{A}-\mu_Z\|<0.015.
   \]
   并且 \(x_{64}^{A}\) 处于某个正确终端稳定驻点的吸引域。继续使用终端噪声迭代，会收敛到该驻点。
2. 对 \(Z=2\)，常值方法满足
   \[
   \|x_k^{C}-\mu_2\|>1.50,\qquad k\ge64.
   \]
3. 预热后跳变方法满足
   \[
   \|x_k^{J}-\mu_0\|>1.29\quad(Z=0),\qquad
   \|x_k^{J}-\mu_2\|>1.50\quad(Z=2),\qquad k\ge64.
   \]
   两种失败均收敛到错误的稳定驻点，追加终端迭代不能修复。

这里 \(k>64\) 表示给每个方法追加相同的终端噪声调用；主比较仍在相同的 64 次预算处进行。对常值方法的 \(Z=0\) 不作统一判断：这个情形接近吸引域边界，不需要它来建立严格增益。

终端目标对三者完全相同：

\[
F_\epsilon(x)=\frac12\|Ax-y\|^2-\lambda\epsilon^2\log p_\epsilon(x),
\quad p_\epsilon=p*\mathcal N(0,\epsilon^2I).
\]

这不是“退火到另一个终端目标”的比较，也不是仅在第 64 步短暂经过正确模板附近的比较。

## 3. 从稳定分支得到的另一条有限步保证

**命题 B（分支存在与保守慢跟踪）。** 对同一参数族、每个标签和每个 \(\eta\in E\)，存在一条 \(C^1\) 驻点分支 \(r_Z(\sigma)\)，\(\sigma\in[0.35,2]\)，连接高噪声唯一驻点与正确终端驻点，并满足

\[
\nabla F_\sigma(r_Z(\sigma))=0,
\]

\[
0.16I\prec\nabla^2F_\sigma(x)\prec2.01I
\quad\text{当 }\|x-r_Z(\sigma)\|\le0.015,
\]

\[
\|r_Z'(\sigma)\|<4.5.
\]

高噪声目标在整个平面上具有大于 0.3 的强凸常数，所以这里的高噪声驻点不是任意挑选的某个局部解。

从规定的反投影初始化先进行 32 次 \(\sigma=2\) 调用，证书推出

\[
\|x_{32}-r_Z(2)\|<0.006.
\]

此后若噪声单调下降、每步变化不超过 \(h\)，定义对应分支距离 \(e_k\)，则在半径 0.015 的邻域内

\[
e_{k+1}\le0.945e_k+4.5h.
\]

只要

\[
0.945\cdot0.015+4.5h\le0.015,
\]

归纳法就推出后续每一步均留在该邻域。此处先验证邻域与初始入口，再用不等式封闭归纳；没有假定“始终跟上”。

一个具体选择是：32 次高噪声预热后，再用 10001 个等间距噪声值从 2 降到 0.35。此时

\[
h=0.000165,\quad K=10033,\quad
e_k\le0.945^k\,0.006+
\frac{4.5h}{0.055}(1-0.945^k)\le0.0135.
\]

终点误差小于 0.017，并进入正确终端不变邻域。两种对照若也使用 10033 次调用，其指定类别的失败仍由命题 A 的终端不变性保证。

**10033 是保守的充分预算，不是必要预算、最优速度阈值或主实验预算。** 命题 A 已独立验证更快的 64 次调用；不能把慢跟踪的界直接套到 64 步并宣称它“始终贴近分支”。

## 4. 可复核的证明

### 4.1 精确梯度、Hessian 和尺度导数

令

\[
v=\tau^2+\sigma^2,\quad q=\frac{\sigma^2}{v},\quad
w_i(x,\sigma)=\frac{a_i e^{-\|x-\mu_i\|^2/(2v)}}{
\sum_j a_j e^{-\|x-\mu_j\|^2/(2v)}},\quad
\bar\mu=\sum_iw_i\mu_i.
\]

精确 MMSE 去噪器及梯度为

\[
D_\sigma(x)=\frac{\tau^2}{v}x+q\bar\mu,
\quad g_\sigma(x)=A^T(Ax-y)+\lambda q(x-\bar\mu).
\]

记

\[
C=\sum_{i<j}w_iw_j(\mu_i-\mu_j)(\mu_i-\mu_j)^T,
\]

则

\[
H_\sigma(x)=A^TA+\lambda q\left(I-\frac{C}{v}\right).
\]

使用两两差分形式计算协方差，可以减少区间计算中的重复依赖。若 \(d_i^2=\|x-\mu_i\|^2\)，则

\[
\partial_\sigma g_\sigma(x)
=\lambda\left[
\frac{2\sigma\tau^2}{v^2}(x-\bar\mu)
-\frac{q\sigma}{v^2}
\sum_{i<j}w_iw_j(\mu_i-\mu_j)(d_i^2-d_j^2)
\right].
\]

沿已证出的分支，隐函数定理给出

\[
r_Z'(\sigma)=-H_\sigma(r_Z(\sigma))^{-1}
\partial_\sigma g_\sigma(r_Z(\sigma)).
\]

高噪声全局强凸性另用 \(\|C\|\le D^2/4\)，其中 \(D\) 为模板直径，得到

\[
H_2(x)\succeq
\left[\lambda_{\min}(A^TA)+\lambda q_2
\left(1-\frac{D^2}{4(\tau^2+4)}\right)\right]I
\succ0.3I.
\]

### 4.2 整段分支的存在、稳定与拼接

把 \([0.35,2]\) 划成 3300 个闭区间，每段长度 \(0.0005\)。每个标签、每一段选择一个有理中心 \(c_{Zi}\)，列在 `candidates.json`。这些中心由浮点求根器提出，但验证器不信任求根器的成功标志、根或导数。

验证器对每个完整尺度区间、整个参数盒、整个 \(E\) 同时验证：

\[
m_{Zi}I\preceq H_\sigma(x)\preceq L_{Zi}I
\quad (\|x-c_{Zi}\|\le0.03),
\]

\[
m_{Zi}>0.16,\quad L_{Zi}<2.01,\quad
\frac{\sup\|g_\sigma(c_{Zi})\|}{m_{Zi}}<0.014.
\]

由于 \(\gamma L_{Zi}<1\)，映射 \(T_\sigma\) 在这个球上收缩。残差条件还推出其将该球映入自身。Banach 不动点定理给出球内唯一驻点，并给出

\[
\|r_Z(\sigma)-c_{Zi}\|<0.014.
\]

相邻中心满足

\[
\|c_{Z,i+1}-c_{Zi}\|+0.014<0.03.
\]

在公共尺度端点，一侧的驻点落入另一侧唯一性球内，因此两侧根相同。逐段拼接得到覆盖整个区间的连续分支；Hessian 非奇异使它局部为 \(C^1\)，并在接缝处一致。两端也与独立验证的高噪声根及正确终端根作同样的唯一性拼接。

实际证书的保守汇总为：

| 类别 | 整段外球 Hessian 下界，大于 | 根到有理中心距离，小于 | 分支速度上界，小于 |
|---|---:|---:|---:|
| 0 | 0.44068 | 0.005342 | 1.895 |
| 1 | 0.16372 | 0.013181 | 2.337 |
| 2 | 0.18031 | 0.011626 | 4.188 |

因根到中心距离小于 0.014，根周围半径 0.015 的球包含在中心周围半径 0.03 的球内。这给出命题 B 的邻域；速度界由上一节公式和区间上界推出。稳定性与分支位置在这里是证书的结论。

### 4.3 64 步误差管：允许局部扩张

对每条方法轨迹，取一个有理参考序列 \(c_0,\ldots,c_{64}\)，同样列在 `candidates.json`。初始半径取

\[
R_0\ge\sup\|A^Ty-c_0\|.
\]

已知真实迭代在 \(B(c_k,R_k)\) 时，在这个完整球内计算 Hessian 谱界 \([m_k,L_k]\)，令

\[
\rho_k\ge\sup\max\{|1-\gamma m_k|,|1-\gamma L_k|\},
\]

\[
b_k\ge\sup\|T_{\sigma_k}(c_k)-c_{k+1}\|,
\quad R_{k+1}=\rho_kR_k+b_k.
\]

由均值公式，真实下一步必落入 \(B(c_{k+1},R_{k+1})\)。球是凸的，所需导数界只作用于已经由归纳证出的当前球，无需假定下一步会进入哪个吸引域。所有上界都包含参数、观测和调度不确定性。

这里允许 \(\rho_k>1\)。对渐进方法，验证结果为：

| 类别 | 过程中最大误差管半径，小于 | 第 64 步到真实模板的距离，小于 |
|---|---:|---:|
| 0 | 0.00499 | 0.0036 |
| 1 | 0.00667 | 0.0048 |
| 2 | 0.02030 | 0.0150 |

这些半径衡量参数不确定轨迹与有理参考轨迹的距离，**不等于到驻点分支的距离**。完整逐步数值保存在 `finite_tubes.json`。

### 4.4 正确和错误终端邻域都是吸引域的可证子集

在终端尺度，围绕每个相关候选驻点 \(c\) 取半径 \(R=0.02\) 的球。验证器证明：

\[
H_\epsilon(x)\succ0.6I,\quad H_\epsilon(x)\prec2.01I,
\quad\rho<0.8,\quad\frac{\|g_\epsilon(c)\|}{m}<0.003,
\]

\[
\rho R+\gamma\|g_\epsilon(c)\|<R.
\]

因此每个球是终端映射的不变收缩邻域，并包含唯一稳定驻点。正确球整体位于真实模板半径 0.021 的邻域内。两个错误球的名义中心约为

\[
c_{0,\mathrm{wrong}}=(0.47016831,-0.07802349),
\quad
c_{2,\mathrm{wrong}}=(-0.49121072,-0.15687508).
\]

对于整个参数族，错误球与真实模板分别相距大于 1.29 和 1.50。第 4.3 节又证出对应对照的 \(x_{64}\) 落入这些球；两步合在一起推出永久失败和错误驻点收敛。无需绘制或假设完整二维吸引域边界，也无需枚举全部驻点。

### 4.5 为什么 64 步不能用“始终贴近稳定分支”来证明

对 \(Z=2\)，在 \(k=50\)（第 51 次调用前），对整个参数盒、噪声事件和调度邻域，已经验证

\[
\|x_{50}-r_2(\sigma_{50})\|>0.50.
\]

取有理向量 \(u=(0.454,-0.891)\)，区间 Rayleigh 商给出

\[
\frac{u^TH_{\sigma_{50}}(x_{50})u}{u^Tu}
<-0.08.
\]

从而实际迭代位置确有负曲率，不只是“某个 Hessian 下界为负、所以无法认证正定”。此时稳定分支本身仍有正定 Hessian。第 4.3 节的逐步管仍然闭合，最终进入正确终端邻域。

这说明“稳定分支存在”与“给定有限预算轨迹始终贴近它”应作为两个不同命题处理。快速路径可以暂时偏离局部收缩区；目前并未证明这种偏离是成功所必需的，也未证明该负曲率阶段独立构成新颖机制。

## 5. 成功概率和无条件平方误差

成功事件仍采用原评估口径 \(\|x_{64}-\mu_Z\|\le0.2\)。设 \(p_E=P(E)\)，标签均匀且与噪声独立。由命题 A：

\[
P_A(\mathrm{success})\ge p_E,
\quad P_C(\mathrm{success})\le1-\frac{p_E}{3},
\quad P_J(\mathrm{success})\le1-\frac{2p_E}{3}.
\]

所以

\[
P_A-P_C\ge\frac43p_E-1,
\qquad P_A-P_J\ge\frac53p_E-1.
\]

这些差值已计入 \(E^c\) 上对照可能胜过退火的最坏情况，不能直接把事件上的失败质量当作无条件增量。

例如，若 \(\eta\sim\mathcal N(0,\nu^2I_2)\)，且

\[
0<\nu\le2\cdot10^{-4},
\]

则由 Mills 界，\(p_E>1-1.2\cdot10^{-6}\)，从而

\[
P_A-P_C>0.3333317,
\qquad P_A-P_J>0.6666646.
\]

这是当前证书能保证的高斯噪声范围，**不覆盖上一轮 \(\nu=0.05\) 的实验**。如果噪声分布完全支撑于 \(E\)，则 \(p_E=1\)，相应增量至少为 \(1/3\) 和 \(2/3\)。

平方误差必须单独控制。对于任意观测噪声、任意预算和 \([0.35,2]\) 内任意调度，利用更新的仿射部分及 \(\bar\mu\) 是模板的凸组合，可得

\[
\|x_K-\mu_Z\|\le7.5+2.2\|\eta\|.
\]

其依据是：仿射部分 \(I-\gamma(A^TA+\lambda qI)\) 的谱范数小于 0.69，初值范数不超过 \(1.76+1.01\|\eta\|\)，每步括号内驱动项不超过 \(3.51+1.01\|\eta\|\)。对几何级数求和即得上述界。

在上述高斯范围内，

\[
P(E^c)<1.2\cdot10^{-6},\qquad
\mathbb E[\|\eta\|^2\mathbf1_{E^c}]<1.296\cdot10^{-12}.
\]

第二式可由独立性、并集界以及
\(\mathbb E[G^2\mathbf1_{|G|>t}]=2(t\phi(t)+\bar\Phi(t))\)
在 \(t=5\) 处得到；更小 \(\nu\) 时逐样本单调性保证上界仍适用。

结合 \((a+b)^2\le2a^2+2b^2\)，得

\[
\mathbb E\|x_{64}^A-\mu_Z\|^2
\le0.015^2+112.5P(E^c)
+9.68\mathbb E[\|\eta\|^2\mathbf1_{E^c}]
<0.000361.
\]

另一方面，

\[
\mathbb E\|x_{64}^C-\mu_Z\|^2\ge\frac{p_E}{3}(1.50)^2>0.749999,
\]

\[
\mathbb E\|x_{64}^J-\mu_Z\|^2\ge\frac{p_E}{3}\left[(1.29)^2+(1.50)^2\right]>1.304698.
\]

所以退火对常值和跳变的期望平方误差改善分别大于 0.7496 和 1.3043。以上为平方欧氏误差，不除以维数。

这是一个小噪声、较强先验下的存在性构造。数据项没有按 \(\nu^{-2}\) 校准，结论不等价于 Bayes 最优恢复或对最优调参常值方法的支配。

## 6. 证书的计算可信边界

`interval.py` 只依赖 Python 标准库。所有输入中心和参数用十进制字符串给出，不接受二进制浮点输入。加减乘除使用向下/向上舍入；`exp`、`sqrt` 的正确舍入结果向两侧各扩展一个可表示数。精度为 42 位。Python `decimal` 的正确舍入语义见官方文档 [5]。

`verify.py` 核对 9900 个完整尺度段的分支证书、有限步误差管、终端不变球、非退化条件、概率与尾部常数。它不信任候选求根器或候选轨迹，只信任这些有理点作为待验证中心。即使换成较差的候选值，验证失败也不会被默认为通过。必须不带 `-O` 运行，脚本会拒绝禁用断言的模式。

# R1：三模板路径选择的几何条件与覆盖范围

日期：2026-10-30。本文是上一版有限预算定理的配套推导。区间验证已通过；仍属于计算机辅助证明草稿，尚未经独立代码审阅或形式化验证。

## 1. 模型及非退化参数族

去噪先验、观测、初始化和迭代为

\[
p=\sum_{i=0}^2\pi_i\mathcal N(\mu_i,\tau^2I_2),\qquad
\pi_i=\frac{a_i}{a_0+a_1+a_2},
\]

\[
y=A\mu_t+\eta,\qquad x_0=A^Ty,
\qquad T_\sigma(x)=x-\gamma\{A^T(Ax-y)+\lambda(x-D_\sigma(x))\}.
\]

这里的干净真值是模板本身；不是从具有分量内方差的 GMM 中随机抽取的点。去噪器是该 GMM 的精确 MMSE 去噪器，正则项不除以噪声方差。

名义值均按精确十进制有理数解释：

\[
\bar\mu_0=(1.38,-1.03),\quad
\bar\mu_1=(-0.22,-0.19),\quad
\bar\mu_2=(-1.16,1.22),
\]

\[
\bar A=\begin{pmatrix}-0.08&0.24\\-0.95&-0.31\end{pmatrix},
\quad \bar\tau=0.15,\quad\bar\lambda=1,\quad\bar\gamma=0.35,\quad\bar a_i=1.
\]

令每个模板坐标、每个矩阵元素、\(\tau,\lambda,\gamma,a_i\) 各自独立变化不超过 \(10^{-4}\)。所有确定性结论同时覆盖整个参数盒。共用各向同性分量协方差是结构约束，不包含任意独立协方差扰动。

本证书重新检查了

\[
0.06I\prec A^TA\prec1.01I,\quad
\min_{i\ne j}\|\mu_i-\mu_j\|>1.69,\quad
|\det(\mu_1-\mu_0,\mu_2-\mu_0)|>1.46.
\]

因此参数族有非空内部，观测满秩，模板不共线，所有方差和权重为正。除特别标注外，观测事件为 \(E_{.001}=\{\|\eta\|_\infty\le.001\}\)，尺度区间为 \([.35,2]\)。参数选定后，各方法共用该参数、观测和初始化。

## 2. 精确改写：一个随尺度变化的高斯混合寻模问题

记

\[
B=A^TA,\quad b=A^Ty,\quad v=\tau^2+\sigma^2,
\quad c=\frac{\lambda\sigma^2}{v},\quad Q=B+cI,\quad t_\sigma=\lambda\sigma^2.
\]

令

\[
w_i(x,\sigma)=\frac{a_i\exp(-\|x-\mu_i\|^2/(2v))}
{\sum_l a_l\exp(-\|x-\mu_l\|^2/(2v))},\qquad \bar\mu_w=\sum_iw_i\mu_i.
\]

则

\[
g_\sigma(x):=\nabla F_\sigma(x)=Qx-b-c\bar\mu_w,
\quad F_\sigma(x)=\tfrac12\|Ax-y\|^2-\lambda\sigma^2\log p_\sigma(x).
\]

完成平方，定义

\[
z_i=Q^{-1}(b+c\mu_i),\qquad \Sigma=t_\sigma Q^{-1},
\]

\[
\widetilde a_i\propto a_i\exp\left[-\frac{\|\mu_i\|^2}{2v}
+\frac{(b+c\mu_i)^TQ^{-1}(b+c\mu_i)}{2t_\sigma}\right].
\]

于是存在与 \(x\) 无关的正常数，使

\[
\exp(-F_\sigma(x)/t_\sigma)\propto
\sum_i\widetilde a_i\exp[-\tfrac12(x-z_i)^T\Sigma^{-1}(x-z_i)].
\]

变换后的责任权重仍然等于原来的 \(w_i\)。由此

\[
T_\sigma(x)=(I-\gamma Q)x+\gamma Q\sum_iw_i(x,\sigma)z_i.\tag{1}
\]

这是带矩阵松弛的 Gaussian mean-shift 更新。一般 \(\gamma Q\ne I\)，因此不能直接把标准 mean-shift 的离散轨迹和吸引域结论搬给 RED。尺度变化时，变换后的中心、协方差和混合质量也同时变化，不只是给固定点集改变一个各向同性带宽。

驻点满足 \(x=\sum_iw_i z_i\)，从而位于三个显式中心的凸包内。这一点将用来从规定初始化推出预热误差界，不必预先知道驻点坐标。

## 3. 第一类条件：白化后的模板竞争

定义白化模板间距

\[
\ell_{ij}^2=\frac c v(\mu_i-\mu_j)^TQ^{-1}(\mu_i-\mu_j)
=(z_i-z_j)^T\Sigma^{-1}(z_i-z_j).
\]

令 \(C_w=\sum_iw_i(\mu_i-\bar\mu_w)(\mu_i-\bar\mu_w)^T\)。Hessian 精确为

\[
H_\sigma=Q-\frac c v C_w
=Q^{1/2}(I-\widetilde C_w)Q^{1/2},\qquad
\widetilde C_w=\frac c vQ^{-1/2}C_wQ^{-1/2}.
\]

利用协方差的成对分解，得到一个可直接解释的标量：

\[
\boxed{\Psi(x,\sigma)=\sum_{i<j}w_iw_j\ell_{ij}^2
=\operatorname{tr}\widetilde C_w.}\tag{2}
\]

它同时衡量“模板有多远”和“当前有几种模板在竞争”。模板很远不必造成不稳定；当一个责任权重接近 1 时，竞争乘积会很小。

**局部充分条件。** 若某凸邻域内 \(\Psi\le\psi<1\)，则

\[
(1-\psi)Q\preceq H_\sigma\preceq Q.
\]

若 \(\alpha=\lambda_{\min}(Q)\)、\(L=\lambda_{\max}(Q)\)，并且 \(0<\gamma L\le1\)，则该邻域内梯度映射的 Lipschitz 常数不超过

\[
\rho=1-\gamma\alpha(1-\psi)<1.
\]

这只给出局部收缩；存在驻点以及迭代是否进入该邻域，还需要下文的残差或不变性条件。

### 3.1 三模板二维情形还有一个精确的面积修正

令

\[
\Delta=\left(\frac c v\right)^2
\frac{w_0w_1w_2\det(\mu_1-\mu_0,\mu_2-\mu_0)^2}{\det Q}.
\]

二维协方差恒等式给出 \(\Delta=\det\widetilde C_w\)，所以

\[
\lambda_{\max}(\widetilde C_w)
=\tfrac12\left(\Psi+\sqrt{\Psi^2-4\Delta}\right).
\]

因而逐点有精确等价关系

\[
\boxed{H_\sigma\succ0\iff \Psi<2\ \text{且}\ 1-\Psi+\Delta>0.}\tag{3}
\]

这说明 \(\Psi<1\) 是保守充分条件，不是必要条件。面积项说明三方非共线竞争与二模板竞争的区别。本轮 101 段证书采用更简单的条件 (2)，没有把 (3) 的潜在收益算入检查数量。恒等式可由 \(\det C_w=w_0w_1w_2\det(\mu_1-\mu_0,\mu_2-\mu_0)^2\) 直接展开证明。

### 3.2 高噪声：完全不需要分支位置的全局条件

定义

\[
\boxed{\kappa(\sigma)=\frac14\max_{i<j}\ell_{ij}^2.}\tag{4}
\]

任意方向上的有限支撑分布方差不超过该方向取值范围的平方除以 4。因此

\[
0\preceq\widetilde C_w\preceq\kappa I,
\qquad H_\sigma\succeq(1-\kappa)Q.
\]

所以 \(\kappa<1\) 推出全局强凸、唯一驻点和全局收缩。这个条件与观测 \(y\) 无关。

对于二维三个非共线模板，还有精确的全局刻画：

\[
F_\sigma\text{ 在整个平面凸}\iff\kappa(\sigma)\le1.\tag{5}
\]

充分性已证。必要性使用两个事实：非共线保证 \(x\mapsto(\log(w_1/w_0),\log(w_2/w_0))\) 是可逆仿射映射；因此责任权重能逼近任意两模板各占一半、第三个权重趋于零的分布。在最远白化模板对上，这使最大协方差特征值趋于 \(\max\ell_{ij}^2/4\)。若该值大于 1，就存在有限 \(x\) 使 Hessian 有负特征值。

在 \(\sigma\ge\tau\) 时，\(c/v\) 随尺度下降而增加，\(Q^{-1}\) 也如此，故 \(\kappa\) 随尺度增加而下降。这里不声称在全部 \(\sigma>0\) 上都单调。

整个参数盒上，区间验证给出

\[
\kappa(1.53)>1.00529,\qquad\kappa(1.54)<0.99431,
\qquad\kappa(1.6)<0.92185.
\]

于是全局凸性转变尺度位于 \((1.53,1.54)\)，且在 \([1.6,2]\) 上

\[
H_\sigma\succ0.08244I\quad\text{对所有 }x.
\]

**覆盖边界：** \(\kappa>1\) 只推出某处存在负曲率，不推出已经有多个驻点，更不等同于正确分支发生分岔。\(\kappa=1\) 也不提供统一的正强凸常数。

## 4. 第二类条件：观测把错误中心拉过分界线了吗

在观测来自模板 \(t\) 时，第 \(j\) 个完成平方中心为

\[
z_j=\mu_j+Q^{-1}B(\mu_t-\mu_j)+Q^{-1}A^T\eta.\tag{6}
\]

令 \(d=\mu_t-\mu_j\)，定义数据拉动比例

\[
\boxed{\chi_{tj}=\frac{d^TQ^{-1}Bd}{\|d\|^2}.}\tag{7}
\]

零观测噪声、相同先验质量时，在错误中心处

\[
\log\frac{w_j(z_j)}{w_t(z_j)}
=\frac{\|d\|^2}{v}\left(\frac12-\chi_{tj}\right).
\]

因此 \(\chi_{tj}<1/2\) 表示观测只把错误模板的二次中心向真实模板方向拉动了不到一半；该中心仍更偏好错误模板。含噪声和非均匀质量的精确式为

\[
\log\frac{w_j(z_j)}{w_t(z_j)}=
\log\frac{a_j}{a_t}+
\frac{\|d\|^2(1/2-\chi_{tj})-d^TQ^{-1}A^T\eta}{v}.
\]

终端尺度 0.35 下，整个参数盒有

| 模板对 | \(\chi\) 的外包区间 |
|---|---:|
| 1 与 0 | [0.29859, 0.30125] |
| 2 与 0 | [0.19003, 0.19242] |
| 2 与 1 | [0.10360, 0.10576] |

第三对的模板距离超过 1.694，但测量距离小于 0.617，且 \(\chi\) 只有约 0.105，这使模板 1 成为模板 2 的强竞争错误解释。

**覆盖边界：** \(\chi<1/2\) 不是失败定理。它没有控制第三模板、邻域稳定性或初始化入口。某模板对满足它，算法仍可能成功。下面的条件补齐这三个缺口。

## 5. 第三类条件：由责任间隙推出不变球与吸引域

以显式代数中心 \(z_j\) 为中心，取闭欧氏球 \(\mathcal B_j=B(z_j,R)\)。对 \(l\ne j\)，令

\[
d_l=\mu_l-\mu_j,\qquad
g_l=\tfrac12\|d_l\|^2-d_l^T(z_j-\mu_j)-R\|d_l\|,
\qquad r_l=\frac{a_l}{a_j}e^{-g_l/v}.
\]

对球内所有点，Cauchy–Schwarz 不等式直接给出

\[
\frac{w_l}{w_j}\le r_l,\qquad w_l\le\frac{r_l}{1+r_l}.
\]

定义

\[
U=\frac{c}{\alpha R}\sum_{l\ne j}\frac{r_l}{1+r_l}\|d_l\|,
\]

\[
h(r)=\begin{cases}r/(1+r)^2,&r\le1,\\1/4,&r>1,\end{cases}
\]

\[
V=\sum_{l\ne j}h(r_l)\ell_{jl}^2+
\sum_{l<m;\,l,m\ne j}r_lr_m\ell_{lm}^2.
\]

**模板主导球引理。** 若

\[
\boxed{U<1,\qquad V<1,\qquad0<\gamma\lambda_{\max}(Q)\le1,}\tag{8}
\]

则 \(\mathcal B_j\) 在终端迭代下严格正向不变，球内存在唯一驻点，并且从球内任意点出发都收敛到它。Hessian 下界为 \(\alpha(1-V)I\)，驻点距 \(z_j\) 不超过 \(UR\)。

**证明。** 由 (1)，

\[
T(x)-z_j=(I-\gamma Q)(x-z_j)+\gamma c\sum_{l\ne j}w_ld_l.
\]

右侧范数不超过 \((1-\gamma\alpha)R+\gamma\alpha RU<R\)，所以球不变。同时 \(w_jw_l\le h(r_l)\)、\(w_lw_m\le r_lr_m\)，从而 \(\Psi\le V<1\)。收缩映射定理给出唯一驻点和收敛。驻点方程再给出 \(\|x^*-z_j\|\le UR\)。证毕。

球的中心不依赖未知驻点；入口条件是可直接验证的距离条件。因而“处于吸引域”是引理结论，不是前提。

### 5.1 正确低噪声分支：三个球覆盖整个尺度带

对 \(j=t\)、\(R=.1\)、\(\sigma\in[.35,.55]\) 和事件 \(E_{.001}\)，整个参数盒上的保守外包界为

| 真实模板 | \(U\) 上界 | \(V\) 上界 | Hessian 下界 |
|---|---:|---:|---:|
| 0 | 0.2120 | 0.2091 | \(0.7184I\) |
| 1 | 0.5606 | 0.6302 | \(0.3359I\) |
| 2 | 0.3486 | 0.4035 | \(0.5418I\) |

每类只用一次连续尺度区间计算，便得到整个低噪声带的正确驻点及其稳定邻域。球的中心因 \(y,\sigma\) 而移动，半径固定为 .1。

### 5.2 两种失败对照的几何解释

终端尺度为 .35。下表中所有数字均向保守方向取整；错误球都以 \(z_1\) 为中心。

| 真值与噪声事件 | 半径 \(R\) | \(U\) 上界 | \(V\) 上界 | 入口距离上界 | 球内重建误差下界 |
|---|---:|---:|---:|---:|---:|
| 模板 0，\(E_{.001}\)，高噪声预热 12 次后 | .14 | .7449 | .9191 | .13568 | 1.1916 |
| 模板 2，\(E_{.001}\)，高噪声预热 12 次后 | .35 | .1088 | .4183 | .23792 | 1.1787 |
| 模板 2，\(E_{.1}\)，反投影初始化 | .35 | .2362 | .8826 | .27677 | 1.1144 |

前两行入口由 12 步高噪声轨迹误差传播得出。第三行直接利用

\[
x_0-z_1=(I-Q^{-1})B\mu_2-cQ^{-1}\mu_1+(I-Q^{-1})A^T\eta
\]

求统一上界，保留初始化与球中心的观测噪声相关性，避免把两个独立区间简单相减造成过大误差。

第三行立即给出本轮新增的失败定理：

\[
\boxed{Z=2,\ \|\eta\|_\infty\le.1
\quad\Longrightarrow\quad
\|x_k^{C}-\mu_2\|>1.11\quad\text{对所有 }k\ge0.}\tag{9}
\]

常值方法一直留在该错误球内，并收敛到其中的错误驻点。此处不需要先跑 64 步再证明它被困住。

这个错误球是**终端映射**的不变球；逐渐改变尺度时，映射也改变，因此退火路径可以离开它。一个点对终端映射被困，并不意味着对所有尺度映射都被困。

同一较大事件 \(E_{.1}\) 上，三个正确终端球也都满足 (8)，且球内误差小于 .175。这证明正确和错误稳定邻域可以同时存在；没有证明渐进调度会进入正确邻域。

## 6. 中间竞争区：101 段怎样建立连续分支

剩余尺度区间为 \([.55,1.6]\)。对每类，用分段仿射曲线 \(q_t(\sigma)\) 作为可计算的参考中心。参考点来自浮点求根，但保存为十进制有理数，验证器不信任求根器的正确性。

在每段 \([b,a]\) 上检查：

1. 整个管状邻域 \(B(q_t(\sigma),R)\) 上 \(\Psi\le\psi<1\)，由此得到 \(m=\alpha(1-\psi)>0\) 和 \(H\preceq LI\)。
2. 整条参考线上的残差上界 \(\sup_\sigma\|g_\sigma(q_t(\sigma))\|\le\varepsilon\)。
3. \(\varepsilon/m<R-.006\) 和 \(\gamma L<1\)。

第二项不检查有限采样点，而使用

\[
\frac d{d\sigma}g_\sigma(q_t(\sigma))
=H_\sigma(q_t(\sigma))q_t'(\sigma)+\partial_\sigma g_\sigma(q_t(\sigma)).\tag{10}
\]

用整个尺度段和整条参考线的区间导数包围此式，再由中点残差与中值公式覆盖连续尺度区间。

对每个固定 \(\sigma\)，

\[
\|T_\sigma(x)-q_t(\sigma)\|
\le(1-\gamma m)R+\gamma\varepsilon<R.
\]

所以每个球内存在唯一驻点 \(r_t(\sigma)\)，且

\[
\|r_t(\sigma)-q_t(\sigma)\|\le\varepsilon/m<R-.006.
\]

相邻段共用完全相同的有理端点中心，端点球同心且嵌套，故两段的根必为同一个。高端与全局唯一驻点连接，低端用显式距离上界进入第 5.1 节正确球。最后由 Hessian 非奇异和隐函数定理推出 \(C^1\) 分支。

| 真值 | 中间段数 | 中间段统一 \(m\) 下界 | 低端拼接距离上界（须小于 .1） |
|---|---:|---:|---:|
| 模板 0 | 23 | .2077 | .02756 |
| 模板 1 | 45 | .0977 | .05207 |
| 模板 2 | 33 | .0997 | .05286 |
| 合计 | **101** | — | — |

每段均保留驻点周围半径 .006 的稳定邻域。由

\[
r_t'(\sigma)=-H_\sigma(r_t(\sigma))^{-1}\partial_\sigma g_\sigma(r_t(\sigma))
\]

及三段区域各自的显式空间包围，证书统一推出

\[
\boxed{\|x-r_t(\sigma)\|\le.006
\Longrightarrow .08I\prec H_\sigma(x)\prec2.01I,
\qquad \|r_t'(\sigma)\|<70.}\tag{11}
\]

这个 70 很保守：中间竞争区三类速度界分别小于 5.66、5.25、12.53；统一大界主要来自高噪声整段的粗包围。

**计数口径：** 9900→101 比较的是连续驻点分支的尺度段数量，约减少 98 倍。新证书还包含高低噪声解析条件、端点拼接和少量预热入口检查；没有把所有计算检查压到 101 次，也没有压缩上一版 64 步误差管。

## 7. 跟踪必须从条件推出：压缩证书能单独保证什么

给定 (11)，令 \(e_n=\|x_n-r_t(\sigma_n)\|\)。若 \(e_n\le.003\)，先在当前尺度更新再改变尺度，则

\[
e_{n+1}\le(1-.08\gamma)e_n+70|\sigma_{n+1}-\sigma_n|.\tag{12}
\]

因此足够的尺度下降条件是

\[
70|\sigma_{n+1}-\sigma_n|\le .08\gamma\cdot.003.\tag{13}
\]

入口也由证书推出：在尺度 2，独立的全局界给出 \(m>.43162\)、收缩因子小于 .84898；驻点凸包性质给出 \(\|x_0-r_t(2)\|<1.674\)。40 次高噪声调用后，三类误差均小于 .00240，从而严格小于 .003。

例如再使用 **1,400,001 个含端点的等间距尺度值**从 2 到 .35，总调用次数 1,400,041，下降步长为 \(1.65/1{,}400{,}000\)。该值满足 (13)，归纳即推出全程 \(e_n<.003\)。最后一次在终端尺度更新后仍在正确驻点的稳定邻域内，重建误差小于 .105。后续终端迭代收敛到该正确驻点。

这只是说明压缩证书本身可以闭合一个有限步定理，不是算法建议，也不是新的预算优势。原证书给出的 10033 次调用慢跟踪界更强，64 步直接轨迹证书又更强。不能用 (11) 推出这些更短预算。

尤其不能把 64 步成功解释为全程稳定跟踪：上一版证出模板 2 第 50 步离对应稳定分支超过 .50，且该点存在负曲率。快速成功仍需要允许暂时扩张的轨迹误差传播。

## 8. 概率、平方误差与覆盖范围审计

若真实标签均匀分布，独立观测噪声为 \(\eta\sim\mathcal N(0,\nu^2I_2)\)，则由 (9)，对于任意调用预算，常值方法有

\[
\mathbb P(\|x_k^C-\mu_Z\|>.2)
\ge\frac13\left[2\Phi\left(\frac{.1}{\nu}\right)-1\right]^2,
\]

\[
\mathbb E\|x_k^C-\mu_Z\|^2
\ge\frac{1.11^2}{3}\left[2\Phi\left(\frac{.1}{\nu}\right)-1\right]^2.
\]

例如 \(\nu=.05\) 时，失败概率下界约为 30.37%。这个式子是对常值方法的单独下界，**没有给出相同噪声下退火的成功概率或相对增益**。

上一版的严格成功概率增量和平方误差改善继续仅按原来的事件与尾部条件成立：64 步退火对 \(E_{.001}\) 全三类误差小于 .015；高概率全局比较使用 \(\nu\le.0002\)。本轮没有重新验证或扩大那组全局增益数值。

| 结论 | 本轮认证覆盖 | 不能由此推出 |
|---|---|---|
| 全局凸性条件与阈值 | 整个参数盒；任意观测；阈值在 (1.53,1.54) | 凸性失去处就是模态分裂点 |
| 正确稳定分支 | 全部三类、\(E_{.001}\)、全部尺度 [.35,2] | 64 步轨迹全程贴近分支 |
| 101 段的统一常数 | \(m=.08\)、半径 .006、速度 70 | 原证书更强的 .16、.015、4.5 常数已被重新压缩证明 |
| 较大噪声下正确终端球 | 全部三类、\(E_{.1}\)、仅终端尺度 .35 | 给定初始化或退火轨迹会进入这些球 |
| 常值失败扩展 | 模板 2、\(E_{.1}\)、全部 \(k\ge0\) | 另外两类也失败；退火在 \(E_{.1}\) 成功 |
| 预热后跳变失败 | 模板 0、2，\(E_{.001}\)，12 次高噪声调用后 | 任意预热次数、较大噪声也失败 |
| 64 步恢复与严格增益 | 继续由上一版证书支撑，范围不变 | 全部更慢调度、任意调度、观测标准差 .05 下的严格增益 |
| 真实信号分布 | 干净信号为三个模板；标签可按给定概率加权 | 对连续 GMM 分量内样本自动成立 |
| 参数扰动 | 所有明确列出的标量独立 ±\(10^{-4}\) | 一般高维、独立协方差扰动或训练去噪器近似误差 |

整个论证没有先假定轨迹处于正确吸引域。正确分支来自残差、自映射和拼接；慢跟踪入口来自高噪声全局收缩；失败来自显式入口距离和不变球。64 步入口另由旧版完整误差管证明。

## 9. 与已有理论的重叠：当前可以怎样定位贡献

Gaussian mean-shift 的固定点方程、EM 解释、责任协方差形式的 Jacobian、局部线性收敛和复杂吸引域已有直接研究 [1]。模态随带宽变化、用 continuation 跟踪模态、尺度空间与退火聚类的关联也已在相关文献中明确讨论 [2]。

式 (1) 表明本例比一般“非凸优化 continuation”更接近这条文献线。由此应调整论证定位：

| 内容 | 当前判断 |
|---|---|
| 协方差控制驻点稳定性；局部收缩；隐函数分支 | 基础工具，不作为新理论贡献 |
| 随噪声尺度跟踪高斯混合模态 | 已有明确相关工作，不能以概念本身主张新增 |
| 此 RED 目标的完成平方与矩阵松弛表达 | 本项目的精确连接与简化工具；不主张首创 |
| 显式弱观测方向、错误主导球、入口与扰动范围联动 | 为本例提供可解释、可检查的几何证明结构 |
| 同初始化、同去噪调用预算、同终端目标下，渐进成功而常值及跳变失败 | 是最应核对的具体定理组合；不能由以上 mean-shift 文献直接视为已经证明，也尚未完成排他性新颖性检索 |
| 快速路径可经暂时负曲率区域仍成功 | 是本例已认证的现象；不等于一条新的一般动力学定理 |

剩余优先问题更明确了：用模板相对观测方向、责任权重间隙和三角形面积，进一步替代中间区 101 段参考曲线；同时寻找能够解释快速轨迹转向的有限步条件。仅把慢跟踪引理写得更一般，不能覆盖当前 64 步机制。

## 10. 复现、可信边界与文件

从工作区根目录运行（路径与输出规则见实验 README）：

```bash
python experiments/code/geometry/verify_geometry.py
```

仅依赖 Python 标准库，读取 101 段有理候选和 12 步预热候选，重新检查完整参数盒、噪声盒、连续尺度区间、拼接与入口，在 `experiments/results/geometry_reproduction/` 输出 `geometry_certificate.json` 和 `sparse_cell_bounds.json`。其中记录实际数值界和候选来源；交付版本的哈希记录随原始结果保留。验证器禁止 `python -O`，因为必须保留断言。

区间核使用 42 位 Decimal；基本四则运算定向舍入，`exp` 和 `sqrt` 在正确最近舍入结果两侧再扩展一个可表示数。所有证书输入都是十进制字符串或整数，不接受浮点数。该实现是短小的自建验证器，尚不是经形式化验证的可信计算内核。

可选的数值交叉检查和作图需要 NumPy、SciPy、Matplotlib：

```bash
python experiments/code/geometry/check_geometry.py
python experiments/code/geometry/plot_geometry.py
```

交叉检查在 500 个随机参数/空间点上独立验证完成平方、责任权重、梯度、矩阵松弛更新及协方差的迹/行列式恒等式，并在 500 个区间内抽样检查缩放系数的包围。它们用于发现实现错误，不取代区间证书。图中曲线和轨迹均为名义参数、零观测噪声的示意。

`make_sparse_candidates.py` 可以重新生成候选，但这不是验证步骤；不同求根库可能产生不同候选或段数。公开的确定候选由独立验证器重新确认，不要求信任候选生成器。

几何验证器只检查本部分的覆盖范围；第一部分的 64 步结论由独立的有限预算验证器检查。两套实现和证据均已纳入当前工作区。
